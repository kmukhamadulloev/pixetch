# Pixetch - Free Pixel Art Editor

Pixetch is a free, open-source pixel art editor that allows you to create pixel art directly in your browser. Whether you're a professional artist or just starting out, Pixetch provides all the essential tools you need to create pixel art.

## Features

- **Multiple Drawing Tools**: Pencil, brush, fill bucket, and eraser
- **Layer System**: Work with multiple layers for complex compositions
- **Color Palette**: Customize your color palette with up to 10 colors
- **Undo/Redo**: Step backward and forward through recent edits with memory-aware history management
- **Export**: Save your artwork in various formats
- **Customizable Canvas**: Adjust canvas size and pixel size to fit your needs
- **History Panel**: Track your changes and revert to previous states

## Usage

### Online Version
Visit [pixetch.k3i.pro](https://pixetch.k3i.pro) to start creating pixel art right away in your browser.

### Local Installation
1. Clone this repository
2. Open `index.html` in your web browser
3. Start creating!

## Tools

- **Pencil**: Basic pixel-by-pixel drawing
- **Brush**: Smooth drawing with adjustable size
- **Fill Bucket**: Fill areas with solid color
- **Eraser**: Remove pixels
- **Color Picker**: Select from your custom palette
- **Layer Management**: Add, remove, and reorder layers
- **Canvas Configuration**: Adjust canvas dimensions and pixel size
